# AI Tools Lab — Portal

Static portal for the 10 AI tools, deployed on Vercel.

- `index.html` — the portal (light premium UI)
- `links.json` — live backend URLs, regenerated by the tunnel watchdog on the VM every time a tunnel rotates and pushed here; Vercel redeploys automatically
- `vercel.json` — static site config

Source of the tools: https://github.com/Shivbu21/ai-tools
